# Windhawk 本地安装与验证

当前版本：0.1.2，包含 x86 / x64 宿主，兼容 Windhawk 1.7.3。

0.1.2 根据系统语言显示中文或英文，修复便携版重启后隐藏设备配置丢失的问题，并兼容旧配置。AirPods 广播接收默认关闭，需要在模组设置中手动开启。源码已提交 [Windhawk 目录审核（PR #7564）](https://github.com/ramensoftware/windhawk-mods/pull/7564)，尚未正式收录。

0.1.1 修复了初版仅允许 64 位宿主的问题：64 位 Windows 上安装的 `windhawk.exe` 也可能是 32 位。模组现在同时提供两种架构，并将界面启动改为异步，避免阻塞初始化。

## 安装

1. 先退出当前独立版“任务栏无线设备电量监控”：点击任务栏电量区域，在菜单选择“退出”。不要卸载，暂时保留用于对照。
2. 用记事本或代码编辑器打开同目录 `taskbar-wireless-battery-monitor.wh.cpp`，按 Ctrl+A、Ctrl+C，复制全部代码。
3. 打开 Windhawk，选择“创建新模组”。
4. 在打开的 `mod.wh.cpp` 编辑器中按 Ctrl+A，再 Ctrl+V，完整替换示例代码。编辑器中的文件名保持 `mod.wh.cpp` 即可。
5. 点击 Windhawk 左侧的编译按钮；Windhawk 侧栏可见时也可按 Ctrl+B。首次编译可能需要一些时间。
6. 编译成功后返回模组页面，确认“任务栏无线设备电量监控”处于启用状态。

这是工具型模组，运行在独立 Windhawk 宿主中；不需要把 DLL 手动放入 Windhawk 安装目录，也不需要注入 explorer.exe。

若提示已经有实例运行，确认独立版已完全退出后，将模组关闭再开启。

## 验证顺序

1. **普通设备**：移动 ROG 鼠标使其唤醒，查看是否出现鼠标图标和电量；悬停查看设备名称，点击菜单可立即刷新。
2. **AirPods**：先在模组设置中开启“接收附近 AirPods 电量广播”，将耳机放回盒内，在电脑旁开盖保持 15～30 秒，查看是否出现耳机图标；悬停查看左右耳、充电盒和充电状态。
3. **设置**：在 Windhawk 的模组“设置”页，将显示模式切换为托盘图标，保存，检查显示是否更新；再切回任务栏。
4. **启停**：关闭模组，确认本模组的电量条/托盘图标消失；再启用，确认恢复。其他程序原有图标不会被删除。
5. **对照**：不要让本模组与独立版同时运行。需要恢复独立版时，先关闭本模组，再从开始菜单启动独立版。

## 限制与故障反馈

- 此本地测试版保留原有内置厂商驱动和 AirPods 解析，暂不调用外部 HeadsetControl 扩展；依赖该扩展的额外耳机支持尚未包含。
- 厂商协议会向设备发送 HID 电量查询报文，部分 ATK 耳机使用串口命令。协议并未逐型号实机验证，部分驱动按厂商 ID 和报文长度匹配；可能与独占设备的厂商工具冲突。
- AirPods 广播电量约 10% 一档，不保证精确到 1%；充电盒值取决于耳机是否发出相应广播。
- 广播归属未经验证，显示“附近广播”。同型号附近有多组时，可能收到其他设备；型号按设备广播标识显示。
- 仅支持主显示器；其他任务栏美化模组、缩放、拥挤布局等组合需另行验证。
- 编译失败时，请将 Windhawk 编译输出中的第一段错误文字发给我；保留行号和错误内容即可。
- 编译成功却未显示时，先确认独立版已退出，并尝试切换“显示模式”为托盘；可在 Windhawk 编辑器中开启本模组日志查看启动信息。

## 重新生成与本地构建

修改多文件源码后运行：

```powershell
python scripts/build-windhawk.py
powershell -ExecutionPolicy Bypass -File scripts/test-windhawk-build.ps1 -WindhawkDir '你的 Windhawk 安装目录'
```

只需向 Windhawk 提供生成的单个 `.wh.cpp` 文件；其他 `.inc` 文件和脚本用于开发维护，不需要用户安装。

编辑器使用方式参考：[Windhawk 官方说明](https://github.com/ramensoftware/windhawk/wiki/Editing-mode-guidelines)。
工具宿主参考：[Windhawk 官方工具型模组方案](https://github.com/ramensoftware/windhawk/wiki/Mods-as-tools:-Running-mods-in-a-dedicated-process)。
